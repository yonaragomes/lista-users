# Lista de Usuários

Projeto React (Vite) que consome a API pública [dummyjson.com/users](https://dummyjson.com/users) e exibe os dados de 30 usuários em cartões.

## Tecnologias

- React
- Vite
- CSS

## Funcionalidades

- Busca de dados via `fetch` com `useState` e `useEffect`
- Componente `User` reutilizável (props)
- Listagem gerada dinamicamente com `.map()`
